# Green Campus Helper 🌱

Green Campus Helper is a simple Java console application created to encourage students and school communities to practice eco-friendly habits and support climate change awareness. The system allows users to register, login, and record different green activities they perform in daily life.

This project was developed as a **group project** using Java and Object Oriented Programming (OOP) concepts.

---

## 📌 Features

- User Registration and Login System  
- Record Green Activities  
- Track Environmental Actions  
- Admin Access for Monitoring  
- Activity Reports  
- Input Validation and Error Handling  
- Simple Console Based Interface  

---

## 🌍 Green Activities Included

Users can record activities such as:

- Saving Electricity  
- Using Bicycle  
- Using Public Bus  
- Planting Trees  
- Reducing Plastic Usage  

---

## 🛠️ Technologies Used
